# MVP V1

Objetivo:
Crear un asistente personal IA básico para apoyo cotidiano.

Funciones V1:
- chat conversacional,
- memoria básica,
- notas,
- tareas,
- recordatorios,
- ayuda digital básica.

Usuarios objetivo:
- trabajadores,
- madres/padres,
- jóvenes,
- personas mayores,
- personas con discapacidad.

Funciones descartadas V1:
- AGI,
- avatar 3D,
- autonomía total,
- emociones avanzadas.
