# AUDIT RULES

## Principios

1. Toda acción importante debe registrarse.
2. Toda automatización debe ser rastreable.
3. Errores deben documentarse.
4. Cambios arquitectura deben registrarse.
5. Decisiones críticas deben justificarse.
6. Supervisión humana obligatoria.
7. Logs deben permitir revisión futura.

## Objetivo
Mantener sistema verificable y sostenible.
