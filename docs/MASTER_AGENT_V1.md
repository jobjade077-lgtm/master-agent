# MASTER AGENT V1

## Objetivo
Coordinar el funcionamiento principal del sistema IA.

## Funciones principales

- gestionar conversación,
- consultar memoria,
- registrar logs,
- responder usuario,
- coordinar herramientas,
- mantener contexto.

## Arquitectura

Usuario
↓
Master Agent
↓
Memory Manager
↓
Logs Manager
↓
LLM
↓
Tools/APIs

## Prioridades

1. estabilidad
2. simplicidad
3. trazabilidad
4. utilidad real

## El Agente Maestro NO:

- actuará sin validación,
- reemplazará supervisión humana.
