# MODEL STRATEGY V1

## Estrategia inicial
Arquitectura híbrida.

## Objetivo
Construir MVP rápido y estable.

## Modelo IA inicial
API temporal durante desarrollo MVP.

## Futuro
Migración progresiva hacia modelos open source.

## Prioridades
- estabilidad,
- bajo coste,
- velocidad desarrollo,
- modularidad.

## NO se realizará en V1
- entrenamiento desde cero,
- fine-tuning complejo,
- infraestructura GPU propia.

## Objetivo técnico real
Crear un sistema útil alrededor del modelo IA,
no competir creando un modelo frontier.
