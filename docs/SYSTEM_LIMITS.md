# SYSTEM LIMITS

## El sistema NO será:

- AGI
- consciencia artificial
- reemplazo humano completo
- psicólogo profesional
- médico
- sistema autónomo total

## El sistema SÍ será:

- asistente cotidiano,
- organizador personal,
- ayuda digital,
- memoria contextual,
- apoyo conversacional práctico.

## Principio principal
Utilidad real sobre complejidad artificial.
