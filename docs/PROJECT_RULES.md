# PROJECT RULES

## Principios

1. Mantener simplicidad.
2. Documentar cambios importantes.
3. Evitar complejidad innecesaria.
4. Priorizar MVP funcional.
5. Mantener arquitectura modular.
6. Registrar errores.
7. Validar antes de escalar.
8. No romper estabilidad existente.

## Objetivo

Construcción sostenible del proyecto.
