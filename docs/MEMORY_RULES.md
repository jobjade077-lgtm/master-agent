# MEMORY RULES

## Reglas principales

1. Guardar solo información útil.
2. Evitar almacenamiento excesivo.
3. Priorizar privacidad.
4. Permitir actualización de memoria.
5. Permitir eliminación de memoria.
6. Registrar cambios importantes.
7. No asumir hechos no confirmados.
8. Mantener contexto reciente accesible.

## Objetivo
Memoria funcional y sostenible.
